# 实时识别与导入识别：前端设计交接 v0.9

日期：2026-10-30。依据：[讨论 #20](https://github.com/bird-assistant/bird-assistant/issues/20)、10 月 29 日会议方向，以及现有 #12 / #13 接口说明。[English](en/10-live-identification-design.md)。

本轮完成可点击的页面、状态和素材交接设计，作为下一步微信开发者工具实现的依据。浏览器原型不调用相机、麦克风或识别服务，不写手机相册；示例取景、分数、录像和相册成功都明确标为演示。观察与导入文件只在当前会话保留；手帐仍可显式保存在浏览器。

## 主要交互

1. 进入识别立即看到取景。相机初始化与后端会话准备独立；正式实现中有权限时尽快显示预览，不等待定位、天气、网络或识别模型。原型用示意鸟画面展示。
2. 快速 / 等候是观察状态，不是用户身份。等候表示后续减少分析；暂停表示停止取景，不能承诺后台仍有此前影像。暂停时不可拍摄，可恢复或导入。
3. 轻触快门保留照片；长按超过 380 ms 演示录像，松开结束；Space/Enter 有等价操作。380 ms 只是原型手势参数。取消指针不保存该次未完成录像；切后台、窗口失焦或确认离开时结束并保留已开始的示例视频。
4. 麦克风按钮控制声音线索；“留鸟鸣”显式保留一段示例声音。相机不可用时仍可保留声音或导入。录像时展示“声音稍后分析”，演示无法并行时的保守降级，不宣称原生并发已可用。
5. 右侧复核按钮结束当前取景。没有主动照片/视频时，正常示例提供最多两张预览质量补救图，默认未选中；暂停、相机拒绝或低存储示例不虚构补救图。导入流程不凭空添加现场帧。
6. 选择照片/视频、音频文件，或使用清楚标注的样例。真实文件仅本地读取；图片必须可解码，媒体播放失败给出提示。原型一次最多六份素材，图片 6 MB、视频 40 MB、音频 20 MB；这些都不是正式平台限制。
7. 预览视频/音频时可选择用于后续分析的时间段。浏览器只保存范围元数据，不导出裁剪文件；默认示例长度和真实文件的初始范围不超过 15 秒。未知时长先等元数据，不能提交无效区间。
8. 复核后可演示识别，也可直接保存待鉴定。模型结果不自动选中鸟种。用户可在复核页选鸟种，在保存页手动填写。所选素材全部随同一观察交接，照片优先作为封面；视频/音频不会被伪装成照片。
9. 近期声音判断与音频文件分开：有声音线索不代表已经保留录音。视觉与声音可能来自不同鸟；不平均分数，不自动归因给画面中的每个目标。
10. 私人观察、加入收藏、地图发布和论坛发布继续分别决定；相册写入状态也不与私人观察保存混为一谈。

## 状态与文案规则

| 条件 | 展示与出口 |
| --- | --- |
| 正常 | 显示鸟框、示例匹配度和单独声音信息；快门立即可用 |
| 名称稳定与更正 | 评阅情景依次演示稳定 → 保留旧判断 → 确认新证据 → 更正，不逐帧跳名字 |
| 结果过时 / 离线 | 移除过期叠框，显示最近线索与等待网络；仍可拍摄 |
| 相机权限关闭 | 显示原因和导入入口；不伪装相机正在工作；声音可独立保留 |
| 声音权限关闭 / 手动暂停 | 明确声音未运行，图像与导入继续可用 |
| 低存储 / 相册保存失败 | 快门素材仍保留在演示会话；显示未保存及重试，不用识别成功冒充保存成功 |
| 识别失败 / 取消 | 保留所选素材、用户鸟名；可重试或存待鉴定 |
| 改选素材 / 分析片段 | 旧分析失效；过期响应不得覆盖新选择 |
| 离开录像 | 先确认结束并保留，或返回录像 |

相对匹配分数不代表正确概率。默认 86% 等数值只是示例，不是测量结果；真实分数、新鲜度和稳定状态以后从接口取得。用户最终鸟名和原始模型判断分开保存。

## 微信实现交接

建议以独立页面/组件组织 identify/index（取景）、identify/import、identify/preview、identify/review 和 observation/edit；实际目录跟随团队选定框架，不重复建工程。复用现有地图、手帐、论坛及个人页导航。

| 边界 | 原生实现职责 |
| --- | --- |
| Capture service | camera 原生组件、实际可用 zoom、照片/视频临时路径、捕获时刻、权限、切后台释放；先验证快门与录音并发 |
| Media repository | 原件与分析副本分离；有界缓存、正式素材保护、相册写入回执、草稿持久化、重启清理 |
| Vision adapter | 按 #12 当前合同建会话、HTTP 图片帧与 WebSocket；单上传、丢弃过时帧；框坐标结合裁切/旋转/镜像映射 |
| Audio adapter | #13 现为录完上传；持续窗口/流式识别另行约定。共用时间基准，无法并行时采用明确降级 |
| Review model | 稳定素材 ID、类型、来源、选择、分析片段、捕获时间精度、保存状态；保留模型原始输出和用户选择 |
| Context | 实时捕获使用实际捕获时刻；历史导入不默认当前位置/天气。首次同意和设置流程后续实现，查询失败不挡拍摄 |

优先验证官方组件实际能力；原生组件不等于所有 OEM 系统相机功能。不要把预览 RGBA 当传感器 RAW，不默认支持 RAW/HDR 双份输出。识别实时帧的编码、端侧模型、自适应采样和约十秒前录缓存仍需设备与服务实验；此次只确定可用的交互与降级，不承诺这些优化已完成。

正式落地前最小真机验证：相机启动和缩放、快门响应、相机录像与麦克风并发、导入格式/解码、低存储与相册拒绝、前后台切换、声音线索关联与过期框。至少记录具体手机、系统、微信版本；覆盖 Huawei Mate/Pura、中端 Android、iPhone 的代表设备。

## 评阅入口

打开 v0.9 后点“识别”。外侧评阅情景可切换离线、结果过时、名称更正、声画分歧、相机/声音权限关闭、低存储、相册失败及原有识别失败/无候选/私人保存失败。紧凑屏幕与 English 用于检查布局。

源码：prototype/dist/recognition.js、recognition.css；接入点位于 app.js、index.html；独立离线包由 scripts/build-offline.mjs 生成。验证记录见 prototype/QA.md。
