# 羽迹下一版功能提案

设计基线为 0.4.18（`17bc941`）。当前五个主入口是首页地图、手帐、识别、讨论和我的。以下四项设计都接在用户正在做的事情后面。第一轮建议验证「这两种怎么分」和「野外速记」。

## 为什么先做这两项

项目问卷中，回答「尚未参与观鸟的原因」的 30 人里，「担心认不出鸟，不知道怎么开始」和「有兴趣，但不知道去哪里、什么时候去」各占 30%。两个比例分别描述该题的选择情况。现有出行顾问已经能给出地点和时段。到了现场，鸟只出现几秒，用户可能只记得脸上一块颜色，或根本来不及拍照。这是这两项设计要验证的使用场景。[团队需求调研第 3 题](../../观鸟助手_需求调研报告.md#33-尚未参与观鸟的原因第3题)

| 参考产品 | 已有做法 | 在羽迹里的设计选择 |
| --- | --- | --- |
| Merlin Bird ID | 用简短问答帮助观察者得到候选鸟种。[官方功能说明](https://www.merlinbirds.org/) | 用户已有两种候选时，只问能帮助区分这两种的特征。 |
| eBird Mobile | 现场清单支持快速录入鸟名和数量，结束时汇总，弱网时可先保存。[官方使用指南](https://support.ebird.org/en/support/solutions/articles/48000957940) | 一次散步对应一页私人手帐，看到、听到、暂时不认识的鸟都能先记下来。 |
| 中国观鸟记录中心 | 小程序提供定点记、随手记和观测点管理。[官方小程序操作手册](https://www.birdreport.cn/home/help/中国观鸟记录中心微信小程序操作手册.pdf) | 同一地点多去几次后，用自己的照片和记录回看变化。 |

## 1. 这两种怎么分

**入口**　在识别结果已有两个候选、且图鉴有经过核对的区分依据时，对比页在两张鸟卡上方显示「这两种怎么分」。也支持用户从图鉴手动挑两种，GPU 忙时仍可使用。

**示例**　用户拍到一只小鸟，正在树麻雀与家麻雀之间犹豫。页顶保留可放大的本人原图，下面问「你看清脸颊了吗？」可选「有一块黑斑」「脸颊看清了，没有黑斑」「脸颊没看清」。选择黑斑后展示树麻雀参考图上的对应位置，以及「这条线索支持树麻雀」。选择没看清时，可以补记现场印象，或带原图和线索去发求鉴定帖。用户最后自己选定鸟种或保留待鉴定。[康奈尔图鉴的麻雀对比](https://www.allaboutbirds.org/guide/Eurasian_Tree_Sparrow/species-compare/)

**首版**　先用现有麻雀对比入口试做一组，再从真实求助帖选第二组。每题标注适用的羽色、年龄与资料来源。题卡随小程序读取，每次作答仅保存用户线索。用户明确选择「待鉴定」的记录保持原状态。

**怎么验证**　让新手分别处理一张特征清晰和一张脸部模糊的照片。前者看能否指出判断部位，后者看能否顺利保留待鉴定。两种结果分开统计。

## 2. 野外速记

**入口**　从地图地点卡点「开始一次观察」，或在手帐点「野外速记」。进来就能记第一笔，时间自动填入，地点可手填或稍后补。

**现场交互**　首屏把「看到」「只听到」放在拇指可达的位置。选鸟名时最近记录优先，也能一键选「鸟名待补」。每笔带时间，「再记 1 只」支持撤销；数量拿不准时可选「数量不详」。相机和录音是可选附件。切出微信再回来，手帐顶部显示「继续这次观察」。

**结束交互**　点「结束并存入手帐」，展示类似「32 分钟 · 4 种已确认 · 2 条待鉴定」的摘要。点一条待鉴定记录就能补照片，而且始终能回到同一次散步。首版按次存为私人手帐，只对用户主动提交的素材发起识别。

**怎么验证**　关闭网络、拒绝定位，连续记录一次目击、一次听声和一次未知鸟。关闭小程序后重开，三笔都应可见。反复点击结束也只生成一份手帐。

## 3. 老地方的四季

**入口**　在收藏地点卡里点「我的历次观察」。第一次来时卡片留一句「给下次的自己留个观察点」，可以选一张代表照片。第二次来时，同一位置显示「和上次比一比」。

**回看体验**　上次和这次的照片并排，下方列出「两次都记到」「这次首次在这里记到」「上次记到」的鸟种。每个鸟名都能点回原始手帐。遇到「只听到」的记录就保留耳朵标记，用户可以看出当时是怎么发现它的。没有照片时仍可对照清单。

**首版与验证**　用户明确选择同一收藏地点后才关联两次手帐。公开鸟讯继续按区域呈现，私人地点由本人控制。先挑有重复到访的用户试用，观察他们能否从对比页说出一次具体变化，并找到支撑它的原记录。

## 4. 圈出来，说说为什么

**入口**　在已有求鉴定帖选完鸟名后，可点「圈出判断依据」。在任意一张帖子照片上点一个位置、调节圈的大小，再写一句话，例如「看脸颊这块深色斑」。原票数旁的「看依据」展开图注，用户可切换候选查看不同解释。

**给发帖人的反馈**　采纳时可同时选一条最有帮助的图注，系统把「采纳的鸟种、被选中的图注和原帖」放在同一张反馈卡上。图注跟随具体照片，点开或放大仍落在同一位置。社区显示作者采纳状态，用户可继续查图鉴复核。

**首版与验证**　每条回复限一张图、一个圈，存照片标识与相对坐标，复用原图。先验两类情况：多图帖中标了第二张照片，返回仍打开第二张；同一人补充或修改图注，候选票数保持正确。

## 开发顺序

先用一组麻雀题验证「这两种怎么分」，同时用一个可断网使用的速记页面验证「来不及拍也能记」。两项核心操作都可以在本机完成，适合现有 GPU 资源。随后根据试用选择方向：经常回到同一公园的用户适合测试「老地方的四季」，有鸟友参与解答的活跃求助帖适合测试「圈出来，说说为什么」。
