## 用户故事卡

优先级和难度为建议，不修改团队排期。

### JRN-01 选择手帐素材

作为手帐创作者，我希望选择手帐素材，以便整理并表达自己的观察，稍后继续编辑。

建议优先级：High；难度：Medium；页面：J02。状态：浏览器交互演示，真实集成未验收。

验收条件：

1. 从相册、自己的观察和自己的收藏照片选材，支持调整顺序。
2. 按观察日期筛选，未知日期可单独包含；不以导入日期替代拍摄日期。
3. 筛选不静默取消已选项，已选列表持续可见。
4. 读取失败或取消选择保留原素材；声音和他人书签不直接作为照片使用。

### JRN-02 生成可编辑初稿

作为手帐创作者，我希望生成可编辑初稿，以便整理并表达自己的观察，稍后继续编辑。

建议优先级：High；难度：High；页面：J03, J04, J06。状态：浏览器交互演示，真实集成未验收。

验收条件：

1. 提供自然手帐、杂志拼贴、极简记录和 3:4、1:1、4:3，此为设计建议。
2. 照片、文字与装饰保留独立对象；导出图不替代可编辑原稿。
3. 只用已有信息，不编造天气、地点或鸟名，待鉴定状态保留。
4. 整体重排先预览再应用，可取消及撤销；提示位置、背景及装饰将重置。

### JRN-03 编辑照片、文字与背景

作为手帐创作者，我希望编辑照片、文字与背景，以便整理并表达自己的观察，稍后继续编辑。

建议优先级：High；难度：High；页面：J04, J05, J06。状态：浏览器交互演示，真实集成未验收。

验收条件：

1. 照片可移动、缩放、旋转、替换和改框比例；裁剪不改写来源图片。
2. 取消裁剪保留原窗口；编辑文字内容、字体、字号、颜色及对齐。
3. 可加删元素、调整图层，设置背景颜色、纹理或图片，支持撤销与重做。
4. 触摸手势与中文字体需微信真机验证，浏览器演示不作为设备验收。

### JRN-04 保存并恢复私人草稿

作为手帐创作者，我希望保存并恢复私人草稿，以便整理并表达自己的观察，稍后继续编辑。

建议优先级：High；难度：High；页面：J01, J04, J08。状态：浏览器交互演示，真实集成未验收。

验收条件：

1. 显式保存后重新加载恢复照片、文字、裁剪与背景，区分本机和云端状态。
2. 保存失败保留编辑，不显示成功；离开未保存内容时提供明确操作。
3. 新建或打开另一份前处理未保存内容；清除本机草稿需单独确认。
4. 保存不自动收藏、发布地图或发帖；云端所有权由后端校验。

### JRN-05 导出与分享成品

作为手帐创作者，我希望导出与分享成品，以便整理并表达自己的观察，稍后继续编辑。

建议优先级：High；难度：High；页面：J07, J08。状态：浏览器交互演示，真实集成未验收。

验收条件：

1. 导出前预览整页，生成匹配比例的 PNG，照片与文字保持一致。
2. 发帖使用成品图副本；打开帖子草稿不等于发布，不影响私人原件或地图。
3. 图中已合成的文字和地点不能靠隐藏附件字段擦除；分享前检查可见内容。
4. 分享按平台支持提供，取消或失败保留编辑；微信分享另做真机验收。

### JRN-06 周期建议保留人工版本

作为手帐创作者，我希望周期建议保留人工版本，以便整理并表达自己的观察，稍后继续编辑。

建议优先级：Later；难度：High；页面：J01, J02, J03, J08。状态：仅概念与设置演示。

验收条件：

1. 仅使用已导入或已保存且可使用的素材，不自动后台扫描手机相册。
2. 建议按时间范围与来源版本去重，未知日期不自动分配到某天。
3. 新素材产生新建议，不覆盖人工编辑版本，也不自动发布。
4. 本轮仅有示例建议卡和周期类型设置，未实现后台调度、AI 或多页年鉴。

## 数据与状态

可编辑手帐包含版本、标题、尺寸、比例、背景、元素数组、来源快照、创建/修改时间和周期标签。照片保留来源、像素尺寸、位置、大小、旋转及裁剪；文字保留正文与样式。未来生成服务应返回受约束布局和文案建议，客户端校验后生成对象。

观察、手帐、成品图与帖子图片分别管理。来源鸟名是快照，不改写原始候选或提升鉴定状态。重排先预览再应用，仍可撤销；分享取消保留编辑。未来周期建议按用户、时区、时间范围和来源版本标识；人工版本独立，具体调度契约待定。

## 演示限制

草稿使用当前浏览器/来源的 localStorage，不是账号同步或生产存储。更换浏览器、移动离线文件可能无法访问原草稿。保存失败保留当前编辑，仍可导出。重置会话保留已保存手帐，清除草稿有独立确认。

演示支持单页1–6张图片、JPG/PNG/WebP单文件6 MB内。导入生成最长边1400像素的预览副本，不修改设备文件，也不读取EXIF。裁剪保留的是该预览副本；正式版需独立媒体存储与原图策略。这些是演示限制，不是最终产品要求。

样例由代码绘制，明确标为插画。字体依赖设备字体和回退，未验证微信字体方案。每日/每周/每月/每年仅标记草稿；建议卡是固定示例，无后台任务。浏览器分享不代表微信接入。PNG中已有文字与地点不能靠隐藏来源字段擦除。

## 与 #12 的连接和未决事项

识别模块交接观察草稿，手帐以后通过统一媒体/观察接口选材，不读取识别页内部状态。拟共享媒体ID、可访问预览、观察时间及精度、用户标签与鉴定状态、可选备注及来源。契约尚未冻结；相册照片不需要识别结果也能创作。

Issue #12开头排除连续相机实时识别，后附视觉接入说明却要求live会话、抽帧与WebSocket；SRS V1.1也将实时识别列入核心范围。须团队确认本期验收边界，不能静默删除任一要求。音频格式/时长、业务网关、单张图片适配和共享基础工程也需对齐。当前main无原生小程序工程，不证明其他分支或组员本地没有。

本稿不修改#12、不分配新负责人，不将手帐混入识别验收。建议单独建立手帐任务，再按当前issue分工开展#12。

## 实施顺序

1. 评阅本轮页面、故事与成品图，确认首轮范围。
2. 复用原生TypeScript工程，验证触摸选中/移动/缩放、裁剪、中文字体、导出及草稿重开；按结果选定开源引擎。
3. 明确#12范围及接口后实现识别模块；手帐保持独立任务。
4. 手帐先打通选材、编辑、持久保存、重开与导出，再接AI，之后加入周期建议与多页汇总。
