# 羽迹观鸟助手产品与交互基线 v0.5

产品载体已由组会确定为微信小程序。当前为故事与交互设计讨论稿，主要用户、最终功能、技术选型和迭代范围仍需结合真实调研决定。

## 产品结构

底部从左到右为首页、收藏、识别、讨论、我的，中央识别按钮较大。首页默认地图。主入口保留状态，拍摄和编辑等专注任务可使用返回及任务操作区。

## 跨页面规则

1. 原始观察默认私人保存。加入收藏、地图发布、论坛发帖是独立选择，可以在同一表单组合表达，而不要求逐个独立页面。
2. 地图和论坛仅公开预览中选定的字段与素材。私人原件后续编辑不静默扩充既有公开内容；按目的地单独预览更新。
3. 私人原件、地图副本与帖子分别管理。撤回一个公开目的地不删除私人原件或另一个公开目的地。
4. 保留原证据、模型建议和用户所选标签。用户选择不等于专家验证；模型分数不称为正确率。
5. 观察记录数、自己的已选择亲历物种数、他人书签分开。待鉴定与他人书签不计入自己的已选择亲历物种。
6. 观察时间、上传时间分开。未知信息保持未知，天气人工填写要标明来源。历史照片不套用今天的天气。
7. 视觉聚合点、稳定地点归属与区域集合边界是不同概念，不能共用一个未说明的规则。
8. 匿名隐藏公开署名与身份入口，内部保留所有权。匿名本身不隐藏公开位置。
9. 好友关系不自动开放所有私人记录。收藏和素材的访问仍依据各自可见范围。
10. 输入校验失败、权限不可用、取消、无可靠候选、分析失败、保存失败和发布失败须有不同状态，并尽量保留素材和输入。

## 当前原型

默认中文，可切换英文，切换不重置当前记录与表单。采用虚构地点与示意地图、示例插画、合成示例声音、模拟识别结果和模拟身份。数据只在本次会话中保留，刷新或重置会丢失新增内容。不会访问真实相机、定位或麦克风，也不向其他人发送通知或消息。本地相册图片只在浏览会话内读取，不上传。

此原型用于验证交互，不证明微信真机集成、AI 准确率、服务器持久保存或真实社交服务已经实现。

## 技术证据与依赖

Issue 6 与 PR 7 为桌面预研。鸟种分类覆盖、微信真机链路和完整端到端表现仍未确立，原型不承诺固定识别时长或成功率。2026年10月22日对所审阅 CSV 与评估器快照的检查发现，该快照的评估器取帧集合交集，遗漏整帧零检测；在所核对配置下，参考召回分母由 291 补至 368，匹配数仍为 188，约从 64.6% 变为 51.1%。这是与另一检测器的一致性，不是人工真值准确率，也没有在本轮重新运行模型。

正式数据来源、区域边界、权限、媒体存储和敏感位置策略仍需团队确认。


### G10 参考资料复用

公开分享、作为参考样本和训练模型是分别决定的用途。只有符合资格且允许复用的素材才能进入参考索引；用户选择或模型建议的鸟名不自动成为已复核样本。保留来源链，对同源转载去重。
