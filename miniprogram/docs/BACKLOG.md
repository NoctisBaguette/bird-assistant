# 羽迹 · 用户需求与验收队列

更新：2026-11-26（北京时间）。[English](en/BACKLOG.md)

本表汇总用户明确提出的需求、后续想法和实际反馈。完整演化保留在 [私人完整开发记录](https://github.com/NoctisBaguette/bird-assistant-miniprogram/blob/main/docs/development-log.txt)；实现依据为当前仓库，而不是旧聊天中的完成表述。

**当前基线**：用户设备保持 **0.4.6**。社区注册、进入相机、导入/查看04鸟图已获用户确认；不能由此推断完整身份、保存、公开发布或模型识别通过。公网视觉就绪接口已在用户网络确认 **Caddy 502**；鸟种名录200、观察接口401保护正常。实际照片识别为 **P0阻断**。

**本轮安排**：主分支只更新文档与记录；0.4.7候选修复在独立评阅分支准备，不要求用户更换当前测试版本，不合并团队PR、不部署服务器。照片手帐/写作/Qwen仍由本工作流负责，不能因视觉服务故障全部转交队友。

状态：**待修**＝尚待实现；**候选**＝本轮评阅代码已准备、待原生验收；**已实现待验**＝0.4.6或更早源码已有，未充分实测；**待部署**＝服务端更新尚未在公网证明生效；**阻断**＝依赖当前不可用；**后续**＝用户要求保留、暂后排；**可选**＝建议而非必交需求。任何源码/单测通过都不等于真机通过。

## 7. 现在可继续的验证与下一批顺序

1. 本轮候选：识别布局六项、主/备用选择器、测量迟到、公共默认连接及真实启动检查；离线回归和源码布局检查。
2. 当前0.4.6可先做：个人头像/字母规则/取消与本机保存；论坛发帖草稿、选图/拍摄参数/预览/返回保留；现有公开帖的图鉴页签与对比。先不提交公开内容。
3. 公共视觉恢复后：手机真实定位和04鸟图 → 双图/无鸟/取消 → 实时/多目标/后台 → 音频/视频接口联调（按实际能力）。
4. 业务接口可用时：用户实际发帖/审核/赞收藏/普通和楼层回复；随后真实Qwen照片手帐、更新后的出行/咨询历史。
5. 语音转写需先由维护者启用，验可编辑预览与确认追加；本论坛推荐检索需配套已审核公开样本。再做账号/个人页全流程、跨设备/适配、动效与外部社区；O01仍可选。
